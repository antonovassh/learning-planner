# 📚 LearningPlanner

A full-stack web application for structured learning management — create goals, break them down into actionable tasks, and track your progress over time.

![Task View](https://github.com/user-attachments/assets/3a0cbc4a-4642-401d-ae96-a48d237a7c4f)

---

## ✨ Features

- **Goal Management** — Define learning goals with descriptions and target dates
- **Task Tracking** — Break goals into concrete tasks and mark them as complete
- **Progress Visualization** — See your overall progress at a glance
- **Clean UI** — Responsive Material UI interface for a smooth experience

---

| Layer | Technology |
|-------|------------|
